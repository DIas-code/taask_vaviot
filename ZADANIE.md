# Тестовое задание — поиск аномалий в потреблении воды

Дан набор данных приборов учёта воды. ID приборов и станций условные.
Показание — накопительный счётчик в кубометрах (м³).

## Главная задача

Из накопительных показаний получить **суточное потребление** (расход за день =
разница показаний между соседними днями) и найти в потреблении аномалии.

Инструмент любой (SQL / Python / Excel / ИИ), но в ответе обязательно
опишите, **как** считали, и приложите скрипт/запрос.

## Файлы

CSV, разделитель `;`, кодировка UTF-8.

| Файл | Поля | Назначение |
|---|---|---|
| `pokazaniya.csv` | `anon_id ; data ; pokazanie ; paketov_za_sutki` | основной файл |
| `pribory.csv` | `anon_id ; bs ; tip ; model ; mesyac_vypuska` | тип/возраст прибора |
| `sobytiya.csv` | `anon_id ; data ; sobytie` (магнит/сброс/Холл) | для сопоставления |

## Что найти (аномалии потребления)

Для каждого пункта: ваш критерий (порог) + сколько приборов + список/примеры
самых ярких `anon_id`.

1. **Отрицательный расход** — показание уменьшилось (счётчик «пошёл назад»).
   Что это может означать?
2. **Всплески** — аномально большой расход за сутки. Дайте и абсолютный порог,
   и относительный (например, в N раз больше обычного для этого прибора).
3. **Нереальные значения** — физически невозможный расход (десятки и тысячи м³
   в сутки). Найдите такие приборы.
4. **Утечка** — непрерывное потребление без «нулевых» суток длительное время
   (прибор никогда не «отдыхает»). Ваш критерий и сколько.
5. **Нулевое потребление** длительно, хотя прибор продолжает слать пакеты
   (пустая квартира / застрявший счётчик). Порог и количество.
6. **Ступенька** — резкое устойчивое изменение уровня потребления
   (например, средний расход во второй половине периода в разы выше первой).
7. Сопоставьте падение/аномалии потребления с событиями «магнит» из
   `sobytiya.csv` — есть ли связь?
8. 2–3 собственные находки по потреблению, которые вы заметили.

## Ожидаем в ответе

- По каждому пункту: метод + число + примеры `anon_id`.
- Скрипт/запрос, которым считали (**воспроизводимость — ключевой критерий**).
- Короткий вывод: какие приборы вы бы отправили на проверку в первую очередь.
